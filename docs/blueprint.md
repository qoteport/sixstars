# **App Name**: sixstars

## Core Features:

- Partner Onboarding: Enable software businesses to register and list their products for sale on the platform.
- Software Portfolio: Showcase software products with detailed descriptions, pricing, and available sales models.
- Needs Analyzer: Enable customers to input their software needs, analyze them against available software, and provide recommendations with detailed reports and exportable results (email, etc).
- AI Recommendation Tool: AI Tool powered by a Large Language Model reasons to produce customized software recommendations based on customer needs.
- Sales Team Interface: Dedicated interface for sales teams to handle customer inquiries, support requests, installation assistance, and training management.
- Customer Support Portal: Provide customer support functionalities to ensure all-round customer satisfaction.
- Customer Account Management: Create and maintain user profiles to track software preferences and sales interactions.

## Style Guidelines:

- Primary color: Deep sky blue (#3399FF) to represent trust and technological innovation.
- Background color: Very light blue (#E5F3FF), almost white, to provide a clean and professional backdrop.
- Accent color: Green (#33FF99) to highlight key CTAs and recommendations.
- Body and headline font: 'Inter', a grotesque-style sans-serif providing a modern, neutral aesthetic for clarity and readability.
- Use modern and minimalist icons for categories and features, enhancing user navigation and visual appeal.
- Employ a clean, grid-based layout to ensure information is well-organized and accessible.
- Implement subtle animations and transitions to improve user experience and guide interaction.
